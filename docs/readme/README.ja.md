> *君は、人類の居住圏の外縁を渡り歩く傭兵パイロットだ。ここで通用するのは、自分の船の砲で守れる掟だけ。企業は小惑星帯で採れる錆びたスクラップや希少金属に高い値をつける。だが、この遠い宙域を根城にする宇宙海賊や敵の哨戒部隊については何も教えてくれない。*
>
> *任務を重ねるたびに、未知の宙域の奥へと踏み込んでいく。次に砕く小惑星が最後になるかもしれない。それでも報酬はいい。この銀河の片隅では、それがすべてだ。ベルトを締めろ、パイロット。虚空が待っている。*

2D宇宙シューティングのキャンペーンを、ひとりでも仲間とでも楽しめます。小惑星を砕き、敵の哨戒部隊と戦い、スクラップや希少金属を集めて任務の合間に機体を強化しましょう。難易度は3段階から選べます。

## ダウンロードと起動

[**最新版をダウンロード**](https://github.com/olegbespalov/rust-in-space/releases/latest)

- **Linux（64ビットのIntelまたはAMD）**。 `.AppImage` をダウンロードし、実行権限を付けて起動します。
- **macOS**。Apple Silicon搭載機は `aarch64-apple-darwin.zip`、Intel搭載機は `x86_64-apple-darwin.zip` をダウンロードします。解凍して **Rust in Space.app** を開きます。

環境ごとの詳しい手順は、英語の[インストールガイド](../installation.md)を参照してください。

## 操作方法

- **メインメニュー**。↑ / ↓ で項目を選び、← / → で設定を変更し、Enterで決定します。ゲーム内の表示言語は **言語** で切り替えられます。
- **作戦説明**。スペースキーで出撃します。
- **飛行中**。← / → で機体を旋回させ、↑ で加速し、スペースキーで射撃します。シングルプレイではEscで一時停止します。
- **一時停止中**。Enterで再開、Escでメインメニューに戻ります。
- **任務達成後**。Enterで **傭兵市場** を開きます。↑ / ↓ で項目を選び、Enterで強化を購入するか、次の作戦説明へ進みます。
- **ゲームオーバー**。Enterでメインメニューに戻ります。

現在のソースコードは、英語、ロシア語、ドイツ語、スペイン語、日本語、簡体字中国語、韓国語に対応しています。選べる言語はリリースによって異なります。

## 仲間と遊ぶ

同じIPv4ローカルネットワークで、最大4人でキャンペーンをプレイできます。メインメニューの **ローカル通信** からゲームを作成するか、参加します。詳しくは英語の[協力プレイガイド](../local-network.md)を参照してください。
