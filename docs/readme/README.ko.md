>
> *임무를 거듭할수록 미지의 우주 깊숙이 들어간다. 당신이 부수는 소행성 하나하나가 마지막이 될 수도 있다. 그래도 보수는 좋다. 은하계의 이 구석에선 그게 전부다. 안전벨트를 매라, 조종사. 공허가 기다린다.*

2D 우주 슈팅 캠페인을 혼자 또는 친구와 함께 플레이하세요. 소행성을 부수고 적 순찰대와 싸우며 고철과 희귀 금속을 모아 임무 사이에 함선을 강화하세요. 세 가지 난이도 중 하나를 선택할 수 있습니다.

## 다운로드 및 실행

[**최신 릴리스 다운로드**](https://github.com/olegbespalov/rust-in-space/releases/latest)

- **Linux (64비트 Intel 또는 AMD)**. `.AppImage` 파일을 내려받아 실행 권한을 부여한 뒤 실행하세요.
- **macOS**. Apple Silicon은 `aarch64-apple-darwin.zip`, Intel은 `x86_64-apple-darwin.zip`을 내려받으세요. 압축을 푼 뒤 **Rust in Space.app**을 여세요.

플랫폼별 자세한 절차는 영어 [설치 가이드](../installation.md)에서 확인할 수 있습니다.

## 조작법

- **메인 메뉴**. ↑ / ↓로 항목을 선택하고, ← / →로 설정을 바꾸고, Enter로 확인합니다. 게임 언어는 **언어**에서 바꿀 수 있습니다.
- **임무 브리핑**. 스페이스바를 눌러 출격합니다.
- **비행 중**. ← / →로 함선을 돌리고, ↑로 가속하며, 스페이스바로 발사합니다. 싱글 플레이에서는 Esc로 일시 정지합니다.
- **일시 정지 중**. Enter로 계속하거나 Esc로 메인 메뉴에 돌아갑니다.
- **임무 완료 후**. Enter로 **용병 시장**을 열고 ↑ / ↓로 항목을 선택합니다. Enter로 업그레이드를 구매하거나 다음 브리핑으로 진행합니다.
- **게임 종료**. Enter를 눌러 메인 메뉴로 돌아갑니다.

현재 소스 코드는 영어, 러시아어, 독일어, 스페인어, 일본어, 중국어 간체, 한국어를 지원합니다. 게임에서 선택할 수 있는 언어는 릴리스에 따라 달라집니다.

## 친구와 함께 플레이

같은 IPv4 로컬 네트워크에서 최대 네 명이 함께 캠페인을 플레이할 수 있습니다. 메인 메뉴의 **로컬 네트워크**에서 게임을 만들거나 참가하세요. 자세한 내용은 영어 [협동 플레이 가이드](../local-network.md)를 참고하세요.
