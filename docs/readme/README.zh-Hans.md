>
> *每一次任务都把你推向更深的未知。你击碎的每颗小行星都可能是最后一颗。不过报酬丰厚，而在银河系的这个角落，这才是最要紧的。系好安全带，飞行员。虚空在等你。*

独自或与好友一起挑战这款 2D 太空射击游戏的战役。击碎小行星、迎战敌方巡逻队，收集废料和稀有金属，在任务间隙升级战舰。游戏提供三档难度。

## 下载并开始游戏

[**下载最新版本**](https://github.com/olegbespalov/rust-in-space/releases/latest)

- **Linux（64 位 Intel 或 AMD）**。下载 `.AppImage` 文件，赋予它执行权限后打开。
- **macOS**。Apple 芯片选 `aarch64-apple-darwin.zip`，Intel 芯片选 `x86_64-apple-darwin.zip`。解压后打开 **Rust in Space.app**。

各平台的详细步骤见英文[安装指南](../installation.md)。

## 操作

- **主菜单**。用 ↑ / ↓ 选择项目，← / → 更改设置，Enter 确认。在 **语言** 一栏切换游戏语言。
- **任务简报**。按空格键出发。
- **飞行中**。← / → 转向，↑ 推进，空格键射击。单人游戏中按 Esc 暂停。
- **暂停时**。按 Enter 继续，或按 Esc 返回主菜单。
- **完成任务后**。按 Enter 进入 **佣兵市场**，用 ↑ / ↓ 选择，按 Enter 购买升级或进入下一场任务简报。
- **游戏结束**。按 Enter 返回主菜单。

当前源代码支持英语、俄语、德语、西班牙语、日语、简体中文和韩语。可选的游戏语言因发布版本而异。

## 与好友联机

同一 IPv4 局域网内最多可有四名飞行员一起打战役。在主菜单选择 **局域网**，即可创建或加入游戏。详情见英文[合作模式指南](../local-network.md)。
