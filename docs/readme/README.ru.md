Корпорации хорошо платят за ржавый лом и редкие металлы из астероидных полей, но умалчивают о вражеских патрулях и космических пиратах, для которых эти далёкие сектора стали домом.*

> *С каждой миссией ты забираешься всё дальше в неизвестность. Любой астероид, который ты расколешь, может стать последним. Но платят хорошо, а в этой части галактики только это и важно. Пристегнись, пилот. Пустота ждёт.*

Проходи кампанию в этом двумерном космическом шутере в одиночку или с друзьями. Разбивай астероиды, сражайся с вражескими патрулями и собирай лом и редкие металлы, чтобы улучшать корабль между миссиями. Выбери один из трёх уровней сложности.

## Как скачать и запустить игру

[**Скачать последнюю версию**](https://github.com/olegbespalov/rust-in-space/releases/latest)

- **Linux (64-битный Intel или AMD)**. Скачай файл `.AppImage`, сделай его исполняемым и открой.
- **macOS**. Скачай архив `aarch64-apple-darwin.zip` для Apple Silicon или `x86_64-apple-darwin.zip` для Intel. Распакуй его и открой **Rust in Space.app**.

Подробности для каждой платформы есть в [руководстве по установке](../installation.md) на английском.

## Управление

- **Главное меню**. ↑ / ↓ выбирают пункт, ← / → меняют настройку, Enter подтверждает выбор. Язык игры меняется в пункте **Язык**.
- **Брифинг**. Нажми пробел, чтобы вылететь на задание.
- **В полёте**. ← / → поворачивают корабль, ↑ включает тягу, пробел стреляет, Esc ставит одиночную игру на паузу.
- **На паузе**. Нажми Enter, чтобы продолжить, или Esc, чтобы вернуться в главное меню.
- **После миссии**. Нажми Enter, чтобы открыть **Рынок наёмников**. Выбери улучшение клавишами ↑ / ↓ и нажми Enter, чтобы купить его или перейти к следующему брифингу.
- **Конец игры**. Нажми Enter, чтобы вернуться в главное меню.

Текущая версия исходного кода поддерживает английский, русский, немецкий, испанский, японский, упрощённый китайский и корейский. Набор языков в игре зависит от выпуска.

## Игра с друзьями

До четырёх пилотов могут проходить кампанию в одной локальной сети IPv4. Выбери **Локальная сеть** в главном меню, чтобы создать игру или присоединиться. См. [руководство по совместной игре](../local-network.md) на английском.
